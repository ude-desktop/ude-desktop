# Developer map: original UDE design

This repository archives original UDE design sketches and explanatory notes. It is not the main source tree for UDE's desktop shell.

## Design topics developers can research

- Desktop shell layout, configurable taskbar orientation and system tray.
- Application launcher: categories, pinned apps, touch-first tiles, overview and launchpad options.
- Window management: multitasking, tiling, decorations, keyboard shortcuts and task switcher.
- Native integration: Linux GNOME/Nautilus, Windows Shell and macOS Finder/LaunchServices concepts.
- UDE Lite versus UDE Full: integration into an existing session versus owning a separate desktop session.

## How to contribute

1. Cite the numbered image or section in [the design archive](design/README.md).
2. Describe a specific user interaction and its input, state and expected result.
3. Distinguish proposed design from tested implementation.
4. Discuss implementation-specific work in [UDE's main repository](https://github.com/ude-desktop/ude).

Related desktop environments (GNOME, KDE Plasma, Windows Explorer shell, macOS desktop) are references for design comparison, not claims of shared code or compatibility.
