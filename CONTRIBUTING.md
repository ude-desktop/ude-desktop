# Contributing to the UDE design archive

This repository preserves original whiteboard sketches and their interpretations. The sketches are the primary design reference.

- Cite the relevant [design page](docs/design/README.md) and sketch number when suggesting a change.
- Separate **original requirements**, **interpretations**, and **implemented** behaviour.
- For screenshots or diagrams, distinguish genuine software from illustrative/mockup material.
- Explain user flows, platform assumptions and accessibility consequences.
- Direct implementation code proposals to the [UDE core repository](https://github.com/ude-desktop/ude).
- Do not replace original sketches with generated illustrations or change attribution without approval.

See [technical focus](docs/technical-focus.md) for design questions that could benefit from developer review.
